Reference catalogs

Each catalog is a set of gene expression programs learned with consensus NMF across one or more datasets, plus rules for deriving discrete annotations from program usage. All catalogs are archived on Zenodo. If you use one, please cite its publication as well as the starCAT paper.

Want to share a reference you built? See the guide to building custom references and get in touch.
